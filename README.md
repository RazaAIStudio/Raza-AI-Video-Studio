# Raza AI Video Studio

Android starter project for the Raza AI Video Studio app.

## Included in this first build
- Native Android app shell
- Text-to-video / image-to-video mode selector
- 9:16, 16:9 and 1:1 aspect-ratio choices
- 720p, 1080p and 4K quality choices
- GitHub Actions workflow to build a debug APK

## Important
This is an interface/build starter, not a working AI video generator yet. Actual generation requires a video-generation provider and a secure backend/API. Never put private API keys in the Android app or public repository. Free unlimited 4K generation cannot be promised.

## Build APK
Push this project to the `main` branch, then open **Actions** in GitHub. Run or select **Build Android APK**. When complete, open the workflow run and download the artifact named `Raza-AI-Video-Studio-debug-apk`.
