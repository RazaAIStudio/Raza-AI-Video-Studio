# Raza AI Video Studio

Android starter project for the Raza AI Video Studio app.

## Included in this starter
- Android app shell
- Select and preview a video from the phone
- Ratio selection buttons: 9:16, 16:9, 1:1
- GitHub Actions workflow to build a debug APK

## Important
This is a starter build, not a complete AI video generator. AI generation and real 4K rendering/export are not implemented or connected yet. Those features need a generation/rendering engine and may have hosting or compute costs. The project is structured so those features can be added in later steps.

## Build
GitHub Actions builds the debug APK on pushes to `main` or when manually started from the Actions tab.
